# 🌸 Florería Rosmery

Bienvenido al repositorio de **Florería Rosmery**, un sitio web diseñado para capturar la esencia y belleza de los arreglos florales, ofreciendo una experiencia de usuario elegante y fácil de navegar.

## 📖 Descripción

**Florería Rosmery** es una aplicación web estática que sirve como escaparate digital para una floristería. El sitio permite a los usuarios explorar una amplia variedad de arreglos florales, ver promociones actuales, conocer más sobre la empresa y ponerse en contacto para realizar pedidos o consultas.

El diseño está enfocado en transmitir emociones a través de una interfaz visualmente atractiva, utilizando una paleta de colores suaves (tonos pastel y rosados) que evocan frescura y elegancia.

## ✨ Características Principales

*   **🏠 Página de Inicio (Home):**
    *   **Carrusel Principal:** Muestra imágenes destacadas de arreglos con descripciones inspiradoras.
    *   **Promociones Populares:** Sección interactiva con un carrusel de tarjetas mostrando ofertas actuales.
    *   **Productos Populares:** Galería de los arreglos más vendidos.
*   **💐 Catálogo Completo:**
    *   Clasificación por tipos de arreglo: Ramos de mano, Centros de mesa, Cajas/Canastas, Premium.
    *   Clasificación por tipo de flor: Rosas, Girasoles, Tulipanes, Orquídeas.
    *   Clasificación por ocasión: Cumpleaños, Aniversarios, Bodas, etc.
*   **🛒 Carrito de Compras:** Enlace directo a la sección de carrito (interfaz visual).
*   **📞 Contacto y Soporte:**
    *   Formulario de contacto modal para pedidos, cotizaciones o reclamos.
    *   Información de contacto directa (Teléfono, WhatsApp) y enlaces a redes sociales.
*   **ℹ️ Sobre Nosotros:** Modal informativo con la historia y misión de la floristería.
*   **📱 Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y escritorio gracias a **Bootstrap 5**.

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido construido utilizando tecnologías web estándar y modernas:

*   **HTML5:** Estructura semántica del contenido.
*   **CSS3:** Estilos personalizados y diseño visual.
*   **Bootstrap 5:** Framework CSS para el sistema de rejilla (grid), componentes (modales, carruseles, tarjetas) y responsividad.
*   **JavaScript:** Lógica para componentes interactivos de Bootstrap.
*   **Bootstrap Icons:** Iconografía vectorial para una apariencia limpia.
*   **Google Fonts:** Tipografías *Poppins* y *Montserrat* para una lectura agradable y moderna.

## 🚀 Instalación y Uso

Al ser un sitio web estático, no requiere de un servidor backend ni procesos de compilación complejos para visualizarse localmente.

1.  **Clonar o Descargar:**
    Descarga el código fuente o clona este repositorio en tu máquina local.

2.  **Abrir el Proyecto:**
    Navega a la carpeta del proyecto y localiza el archivo `index.html`.

3.  **Ejecutar:**
    Haz doble clic en `index.html` para abrirlo en tu navegador web predeterminado (Chrome, Firefox, Edge, etc.).

    *Opcional:* Para una mejor experiencia de desarrollo, puedes usar una extensión como "Live Server" en Visual Studio Code.
